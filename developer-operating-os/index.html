Before you begin

Start Here

Every developer hits the same three walls.

Underwriting backs up. Deals sit in the inbox for a week because nobody has time to run the numbers. The good ones get bought by someone faster.

Capital raises run on memory. Who said yes, who went quiet, what you promised in the last update. It all lives in your head and your inbox.

Deals slip through the gaps. Owners you meant to follow up with. Sites you never got around to scoring. Offers that lost on structure, not price.

This playbook gives you 40 agents that take those walls down. Each one does a job your analyst, associate or assistant would do. You stay the one who decides.

What an agent is

An agent is a set of written instructions that Claude, a work assistant made by Anthropic, follows to do one job for your firm with your own numbers. It scores the site list, builds the first appraisal, drafts the investor update. You check it and make the call.

You can run an agent two ways. Paste it into a chat when you need it. Or, for the jobs that repeat, put it on a schedule so it runs every week without you asking.

There is no code to write and no new software for your team to learn. If you can copy cells from a spreadsheet and paste them into an email, you can run every agent in this playbook.

What changes when your agents are running:

  • You screen and close more deals each quarter. Every inbound deal gets a fast, consistent first look. Every owner gets followed up. Every offer gets a structure built to win.
  • You underwrite faster, with fewer blind spots. A first-pass appraisal, a stress test and an investment committee memo, built from your numbers and checked against your own buy box.
  • You raise more capital. Sharper pitches, a clean raise pipeline, and investor updates that keep people confident enough to come back for the next deal.

Prompt: Project instructions

This one has no brackets to fill in. If you work in the UK, change "US spelling" to "UK spelling."

The prompt
You are the operations analyst for a real estate development firm. You do the work that usually sits with an analyst, an acquisitions associate, an office manager and a bookkeeper. Return work that is finished, checkable and ready to act on.

THE FIRM
My Firm Context File is in this Project's files. Read it before every task. Never ask for something it already answers. If a task needs something the file does not cover, say what is missing and ask.

THE RULES YOU WORK BY
1. Never invent a number. If a figure is missing, name it and tell me where to get it. An output with a marked gap is better than a complete output that is quietly wrong.
2. List your assumptions. Every output that involves math ends with an ASSUMPTIONS block.
3. Do the math properly. If you can run code, use it for calculations, and show your working so I can check it.
4. Flag what needs a professional. Anything touching law, tax, valuation, zoning or planning approval, or tenant compliance gets marked COUNSEL REVIEW REQUIRED or ADVISER REVIEW REQUIRED. You prepare the work. A qualified person signs it off. Say when rules vary by jurisdiction.
5. Mark what is unverified. If you have not seen the source, label it UNVERIFIED and say where to confirm it. Never present a listing, a zoning fact, a title fact or a market figure as confirmed when it came from inference or general knowledge.
6. Give me something I can use. Tables for data. Checklists for actions. Draft text for anything I will send. Every action has an owner and a date. Do not end with a summary of what you just did.
7. Say what to do next. End with one line: the single most valuable next action.

YOUR VOICE WHEN YOU DRAFT FOR ME
Short sentences. Direct. No filler. No em dashes. Use US spelling. Write the way an operator writes to a seller, investor, lender, tenant or contractor. Not the way a marketer writes. No "I hope this email finds you well." No "circling back." No "excited to share."

RUNNING AGENTS
When I paste an agent prompt, run it. If an input it needs is missing, ask me for it one question at a time before you start. If I describe a problem instead, solve it directly.

Your first run

You will do this the same way every time.

  1. Open a new chat inside your Project.
  2. Copy the prompt for the agent you want. Every prompt has a Copy prompt button.
  3. Fill in the brackets you know. Leave any you're unsure about. Claude will ask.
  4. Paste your data where the prompt says to.
  5. Send it. Answer any questions Claude asks.
  6. Push back like you would with an analyst. "Show me how you got that number." "That comp is wrong, use this one." "Make the letter shorter." Each round gets sharper.
  7. Save what you use. Paste the final version into your own files or tools.

Most agents take a few minutes to run once your data is ready. Getting the data together is usually the longest part, and it gets faster every time.

Keep your data safe

Only paste data you are allowed to share. If your firm has a policy on outside tools, follow it. Check the privacy and data settings on your Claude plan before you load investor details, personal information or anything under a confidentiality agreement.

One thing to be straight about

Claude is very good at structure, drafting and catching what you missed. It is not a calculator you can trust blind. It can make an arithmetic mistake inside a correct method, and it will sound sure of itself.

So check the numbers before anything leaves your building. An investor distribution. A payment run. A covenant test. An offer price. Every agent in this playbook asks Claude to show its working so you can check it quickly. Some prompts also tell Claude to use code for the math. That's Claude's own calculator. You don't write or run anything.

Treat every output as a draft from a fast, sharp analyst. You still sign it off.

Find More Deals

The best sites never hit the market. They sit with owners who have held for 20 years, live in another city, or own through a company nobody has looked into. Whoever reaches those owners first, and keeps following up, gets the deal.

That work is slow and repetitive, so it rarely gets done properly. These five agents do it for you, every week. Score your property list. Find the real owner. Write to them. Follow up for a year without being a nuisance. Review your whole pipeline every Friday.

What changes: more owners in real conversations, fewer deals lost to silence, and a clear view of which deals deserve your time this week.

One rule for this chapter. Claude doesn't have your county's property records. Pull them from your assessor, land registry or data provider, and paste them in. The agent does the analysis. You supply the facts.

Chapter 4

Build on Budget

Margin is made in underwriting and lost in construction. Rarely in one hit. A budget that was light from day one. A contract awarded on the lowest headline price that turns out to leave out half the scope. Change orders, or variations, signed on site because the crew is standing around waiting. A weekly report that says "on track" because nobody checked it against the draw.

These four agents put a check at each of those points. Challenge the contractor's budget before you sign. Level the bids so you compare like for like. Review every change order before it becomes part of the contract sum. Then get a weekly report that tests what the team says against what the schedule and the numbers show.

What changes: budgets you can defend, contracts awarded on real cost instead of headline price, fewer change orders signed blind, and site problems on your desk while there is still time to act.

One rule for this chapter. Construction arguments are won on the contract wording. Paste the relevant clauses every time. Anything that turns on what the contract means goes to your lawyer before you act on it.

Chapter 5

Protect Your NOI

Your asset is worth its NOI divided by a cap rate. You don't control the cap rate. You do control the NOI, and it rarely falls off a cliff. It leaks. A lease date nobody caught. A repair that dragged for six weeks and cost you a good tenant. Arrears nobody chased until they were three months deep. Capex spent on the lobby while the roof waited.

Each leak looks small on its own. Together they show up in the valuation, the refinance or the sale, and by then they are expensive to fix.

These five agents catch the leaks every month. Review every asset against budget and underwriting. Keep a lease diary that never misses a notice date. Triage repairs and hold contractors to their response windows. Collect rent and check the rent roll against the bank. Spend capex in the right order.

What changes: problems caught in the monthly numbers instead of the valuation, fewer missed dates and lost tenants, and capex spent where it protects or adds value.

On tenants and notices. Landlord and tenant law is local and strict. Notice periods, rent increase rules, deposit rules and safety duties change by country, state and lease type. These agents track the dates, do the math and draft the informal letters. Anything formal goes to your lawyer or managing agent before it is served.

Chapter 7

Never Miss a Deadline

Every deal and every project runs on dates. A notice period on a lease. A longstop or outside date in a land contract. An option that expires on a set day. A condition that must be cleared before you can start on site. An annual filing for every company in the structure. A safety certificate on every building you own. Miss one and it costs real money: a lost deposit, a lapsed option, a stopped site, a penalty.

Those dates live in contracts, in inboxes and in someone's memory. Usually somebody knows the date. The problem is that nobody starts the work early enough to hit it.

These three agents pull every date into one place and work backward from it. One register for every legal, company and compliance date. A tracker for planning and permit conditions. And a way to turn agreed terms into a draft on your own contract template, with every date pulled out as you go. You act before the deadline, not on it.

What changes: no more dates discovered the week they fall due, an owner and a start date on every deadline, and sharper, cheaper instructions to your lawyer.

One rule for this chapter. These agents prepare work for your lawyer. They do not replace legal advice. They find the dates, count them and list the questions. Your lawyer decides what a clause means and what happens if a date is missed.

Get Your Week Back

In most firms the founder is the CRM, the task tracker and the Friday-night report. Every relationship, every promise made in a meeting and every number Monday needs lives in one head and one inbox.

So things slip. A lender goes cold because nobody logged the last call. An action from Tuesday's site meeting never gets done because nobody owned it. Sunday afternoon goes to pulling together what Monday needs.

These three agents run the firm's admin rhythm. Keep every contact current and know exactly who to call this week. Turn every meeting into owned tasks with dates. Start Monday with one page, not a weekend of prep.

What changes: fewer relationships lost to silence, fewer actions lost after meetings, and a week that goes to deals and capital instead of admin.

One rule for this chapter. These agents draft. You send. Claude writes the call notes, chasers and re-engagement messages. Nothing goes out until you, or the person you hand it to, has read it and sent it.

  3. Check the resultEvery touch is dated in your calendar or CRM, and the stop rules are written on the contact record.

The prompt

The prompt
You are my acquisitions follow-up strategist. Owners rarely sell on the first contact. Persistence wins, as long as every touch is useful. Build me a sequence that stays useful and never becomes a nuisance.

Target: [OWNER OR BROKER NAME, OWNER TYPE, SITE ADDRESS]

[EACH TOUCH: DATE, CHANNEL, WHAT WAS SENT OR SAID, RESPONSE OR SILENCE]
Last outcome: [e.g. no response, "not interested", "call me next year", asked for a number, referred me to their lawyer]
Channels I can use: [e.g. mail, email, phone, in person, broker intro]
Deal priority: [A, B OR C]

Build a 12-month sequence.

1. Read the last outcome and classify it: hard no, soft no, timing objection, price objection, silence, or engaged. Say which, and what evidence supports it.

2. Set the cadence from the classification.
   - Silence: a touch every 21 days for the first 90 days, then every 60 days.
   - Soft no or timing objection: acknowledge it and go quiet for 90 days, then one useful touch every 90 days.
   - Hard no: one polite close-out note, then one touch a year. Nothing else.
   - Price objection: a 30-day gap, then come back with structure, not price. Longer close, seller financing, leaseback, phased payment.
   - Engaged: every 3 to 5 days until a meeting is booked.

3. Every touch needs a reason to exist. Rotate through: a market fact about their street, a nearby comparable sale, a zoning or planning change that affects their land, a project of ours nearby, a specific structure offer, or a genuine question. Never "just checking in." If a touch has no reason, cut it.

4. Vary the channel. Never use the same channel three times in a row.
5. Set stop rules. Stop completely if they ask me to stop, the property sells, they sign with another buyer, or I get three hard nos in a row.

Edge cases. If the history shows more than six unanswered touches in 90 days, tell me plainly to stop and go quiet for 6 months. If the last outcome mentions a lawyer or agent, send every future touch through them and note why.

Run agents on a schedule

21 of the 40 agents do a job that repeats. Set each one up once as a scheduled task in Claude, and it runs on its own. The other 19 start when something happens, like a counteroffer or a change order, so you run those by hand.

How to set one up

  1. Open the agent's page below and scroll to Run it on a schedule.
  2. In Claude, open Scheduled in the left sidebar. Click New task, then Set up manually.
  3. Copy the task name and the task instructions from the agent's page. Fill in where your files live.
  4. Set how often it runs: daily, weekdays or weekly, as the agent's page says.
  5. Save. Each run opens its own session. Read it and check it against Done when.

Prefer to talk it through? In any Claude chat, say what to run and how often, answer its questions, and click Schedule.

Good to know before you start
  • Keep your files in Google Drive. Scheduled tasks keep running while your computer is asleep, unless they need files stored on your computer. Connect Google Drive, and Gmail where an agent reads email, in Claude's settings.
  • A scheduled run starts fresh. It can't ask you questions, so the task instructions tell Claude where your Firm Context File and data live, and to list anything missing instead of guessing.
  • Monthly and quarterly agents run weekly and skip themselves. Claude's options are hourly, daily, weekdays and weekly, so the instructions tell the agent to stop with "Not due" until its week comes round.
  • Everything is a draft. The instructions tell Claude not to send, delete or change anything. You read the result and act on it.
  • Scheduled runs use your plan's usage, the same as chats. Start with two or three agents, not twenty.
